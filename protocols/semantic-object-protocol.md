# Semantic Object Protocol v0 Draft

A model-independent representation for semantic objects exchanged by SCA-X components and agents.

Each object should carry: id, type, subtype, attributes, relations, confidence, provenance and observed_at.

Design goals: language independence, model independence, serializability, provenance preservation, uncertainty awareness and extensibility.

The protocol is intentionally a draft. Issue #1 tracks the v1 specification.
