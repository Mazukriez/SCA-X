# How to Build the Next SCA-X Cognitive Engine

1. Freeze the deterministic MVP as a baseline.
2. Define typed semantic objects and relations.
3. Implement a persistent Cognitive State Graph.
4. Define memory interfaces for episodic, semantic, procedural and causal memory.
5. Replace template hypotheses with modular reasoning operators.
6. Define a state-transition algebra with preconditions and effects.
7. Build a transition planner.
8. Build a simulator and keep it separate from execution.
9. Add predicted-vs-observed experience learning.
10. Add optional neural adapters without making them authoritative.
11. Build reproducible benchmarks and compare against an LLM-agent baseline.
12. Only then evaluate broader intelligence claims.

Every architectural improvement should have a baseline, scenario set, metric, result and failure analysis.
