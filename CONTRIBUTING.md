# Contributing to SCA-X

SCA-X is a research-engineering project. Fork the repo, create a focused branch, read docs/architecture.md and docs/build-next-engine.md, add tests, run npm test and npm run build, then open a PR.

For algorithmic changes document the problem, hypothesis, mechanism, baseline, evaluation method and failure modes. Keep the cognitive kernel provider-neutral; proprietary or neural-model integrations belong behind adapters. Never commit secrets or sensitive incident data.
